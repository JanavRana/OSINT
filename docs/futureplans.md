### 1. 📧 **Email & Data Breach OSINT APIs**

* **HaveIBeenPwned (HIBP) API** (`haveibeenpwned.com`)

* **Hunter.io API** (`hunter.io`)
  * **What it adds**: Email deliverability score, corporate email pattern verification, and associated organization details.
* **EmailRep.io API** (`emailrep.io`)
  * **What it adds**: Free email reputation score, spammer rating, domain age, and public social profile indicators.

---

### 2. 🌐 **Domain, IP & Network Intelligence APIs**

* **VirusTotal API** (`virustotal.com`)
  * **What it adds**: Threat intelligence ratings, malware flags, malicious domain detections, and SSL certificate histories for domains & IPs.
* **Shodan API** (`shodan.io`)
  * **What it adds**: Open ports, running services (HTTP, SSH, FTP), server vulnerabilities (CVEs), and infrastructure details for any IP address.
* **SecurityTrails API** (`securitytrails.com`)
  * **What it adds**: Historical DNS records (past A/AAAA records, MX history) and complete subdomain enumeration for target domains.
* **AbuseIPDB API** (`abuseipdb.com`)
  * **What it adds**: Community abuse confidence scores, reported spamming/DDoS activity, and malicious IP classifications.

  * **What it adds**: Live Bitcoin wallet balances, total received/sent amounts, and transaction graph connections.
